# Provider boundary

`MarketDataProvider` and `TiingoMarketDataProvider` implement metadata, daily history and latest EOD observations. Retain this abstraction even though Tiingo is the sole MVP market-price implementation. `SecEdgarProvider` resolves SEC ticker/CIK identity and retrieves submissions/companyfacts using a real contact User-Agent, with no API key. Inject validated `AppConfig`; never read `process.env` at module load. Keep credentials and adapter-owned URLs backend-only, validate provider responses, and use bounded requests with safe error codes. Provider requests occur only inside explicit sync actions. Preserve valid PostgreSQL cache on failures and report stale/unavailable data; no fallback is configured. OpenAI news/qualitative research remains a later phase, completing the three-provider MVP. See `docs/TIINGO.md` and `docs/SEC_EDGAR.md` for normalization, limits and coverage boundaries.
