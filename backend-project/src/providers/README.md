# Provider boundary

`MarketDataProvider` and `TiingoMarketDataProvider` implement metadata, daily history and latest EOD observations. Retain this abstraction even though Tiingo is the sole MVP market-price implementation. Inject validated `AppConfig`; never read `process.env` at module load. Keep credentials and adapter-owned URLs backend-only, validate provider responses, and use bounded requests with safe error codes. Provider requests occur only inside explicit sync actions. Preserve valid PostgreSQL cache on failures and report stale/unavailable data; no fallback is configured. SEC EDGAR filings/fundamentals and OpenAI news/qualitative research remain later phases, completing the three-provider MVP. See the root `docs/TIINGO.md` for precision, quotas, adjustment rebasing and calendar boundaries.
